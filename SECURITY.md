# Security Policy

## 🔒 Supported Versions

Security fixes are prioritized for the latest version of BroNetwork.

Older versions may not receive security updates. Please update to the latest version before reporting an issue, if possible.

## 🚨 Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a potential security vulnerability in BroNetwork, please report it privately to the maintainer.

Include the following information when possible:

- A description of the vulnerability.
- The affected component or file.
- Steps to reproduce the issue.
- The potential impact.
- Relevant logs or screenshots, with sensitive information removed.

Please avoid sharing passwords, access tokens, private keys, personal information, or other secrets in your report.

## ⏳ Response Expectations

The maintainer will review reports as soon as reasonably possible.

Response times may vary because BroNetwork is maintained by an individual developer who may occasionally be unavailable.

Please allow time for investigation before publicly disclosing a vulnerability.

## 🛠️ Disclosure

Please coordinate with the maintainer before publicly disclosing an unpatched vulnerability.

Once a fix is available, the issue may be disclosed with appropriate details to help users protect themselves.

## 💙 Thank You

Thank you for helping keep BroNetwork and its users safe.
