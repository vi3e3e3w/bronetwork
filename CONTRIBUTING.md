# Contributing to BroNetwork

First off, thank you for considering contributing to BroNetwork! ❤️

Every contribution, whether it's a bug fix, a new feature, documentation, or a suggestion, is appreciated.

## 📋 Before You Start

- Check existing issues and pull requests to avoid duplicate work.
- For major changes, open an issue first to discuss your proposal.
- Keep contributions focused and easy to review.
- Be respectful to other contributors.

## 🐛 Reporting Bugs

When reporting a bug, please include:

- A clear description of the problem.
- Steps to reproduce it.
- Expected behavior and actual behavior.
- Relevant logs or error messages.
- Your operating system and Python version, if relevant.

**Please remove passwords, tokens, personal information, and other secrets from logs before posting them.**

## 💡 Suggesting Features

Feature suggestions are welcome!

Please explain:
- The problem the feature would solve.
- How you expect it to work.
- Any alternatives you have considered.

## 🔧 Submitting Changes

1. Fork the repository.
2. Create a branch for your changes.
3. Make your changes and test them.
4. Commit your changes with a clear commit message.
5. Push your branch to your fork.
6. Open a pull request against the appropriate branch.

Example:

```bash
git switch -c fix/short-description
# Make your changes and run relevant tests
git add .
git commit -m "Fix: describe the issue"
git push -u origin fix/short-description
```

## ✅ Pull Request Guidelines

Please make sure that your pull request:

- Explains what changed and why.
- References related issues, if applicable.
- Includes tests or testing instructions when relevant.
- Updates documentation when necessary.
- Does not include unrelated changes.

The maintainer may request changes before merging.

## 🧪 Testing

Run the relevant tests before submitting your pull request.

If automated tests are unavailable, explain how you tested your changes and mention any limitations.

## 🔐 Security Issues

Please do not publish sensitive security vulnerabilities in public issues.

Contact the maintainer privately through an appropriate channel listed in the repository.

## 🤝 Code of Conduct

Be kind, respectful, and constructive.

Harassment, personal attacks, and deliberately disruptive behavior are not welcome.

## 📄 License

By contributing to BroNetwork, you agree that your contributions will be distributed under the repository's existing license, unless explicitly agreed otherwise.

Please review the repository's `LICENSE` file before contributing.

## 💙 Thank You!

Thank you for helping improve BroNetwork.

Happy contributing!
